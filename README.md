# Centre de Formation

## Description

Site Web d'un centre de formation réalisé
dans le cadre du module Développement Web
et Multimédia.

## Fonctionnalités
- Présentation du centre.
- Affichage des formations.
- Calculatrice de prix.
- Formulaire de contact.
- Interface responsive.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Structure du projet

- index.html
- css/style.css
- js/script.js
- images/

## Lancement du projet

Ouvrir le fichier index.html avec Live Server.
